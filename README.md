# Boston

University project from the subject 'Metodología de la Programación'.

The name 'Boston' comes from the USA city, as the project consisted on working with several crimes ocurred 
in this city between 2017 and 2021. These crimes would be classified and represented in a heat map. 

During the practical sessions, classes to modulate and solve easier problems were implemented. Moreover, 
it was implemented some operative apps for the data analysis and handling (data lecture and filtering, stadistic estimations).
Also, this project taught datasets fusion and the creation of a coloured image of the heat map.
