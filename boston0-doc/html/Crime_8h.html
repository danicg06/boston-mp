◆ Normalize()

void Normalize ( Crime &  crime)

Normalizes every string field in the provided Crime object. That is:

  1. It removes spaces and \t characters at the beginning and at the end of every string field
  2. It converts to uppercase every string field For the ID field only the conversion to uppercase is necessary because an ID cannot contains leading or trailing blanks

◆ Trim()

void Trim ( std::string &  myString)

Removes spaces and \t characters at the beginning and at the end of the provided string myString. If the provided string myString is empty or contains only spaces or \t characters then myString will contain an empty string after calling to this function.

Note
This function can be easily implemented using the methods find_first_not_of(string) and find_last_not_of(string) of class string.
