Detailed Description

Used to represent dates and times in the format YYYY-MM-dd hh:mm::ss, where.

YYYY-MM-dd hh:mm:ss
+----+----+----+----+
| | | | |
0 5 10 15 20

  • YYYY Year Any value allowed
  • MM Month values in [1,12]
  • dd day values depending on the calendar
  • hh hour values in [0,23]
  • mm minute values in [0,59]
  • ss seconds values in [0,59]

The hour is in the UTC (Coordinated Universal Time) format.

DateTime::DateTime ( const std::string &  date)

Constructor that builds a DataTime from the data in the provided string. If the string contains a valid date and time, it builds an object with the provided content; otherwise it builds an object with the default DateTime. See DateTime::DATETIME_STRING_DEFAULT.

Precondition
The provided string date must be in the correct format (YYYY-MM-dd hh:mm:ss), that is no errors of conversion is obtained when using stoi() for each field.
