{\footnotesize\ttfamily int main (\begin{DoxyParamCaption}\item[{int}]{argc,  }\item[{char \texorpdfstring{$\ast$}{*}}]{argv\mbox{[}$\,$\mbox{]} }\end{DoxyParamCaption})}

The purpose of this program is to read a set of data on crimes committed in the city of Boston, showing those that have occurred within certain geographic coordinates and within the date range provided to the program. This program first reads from the standard input two \doxylink{classCoordinates}{Coordinates} objects, one \doxylink{classCoordinates}{Coordinates} to define the minimun coordinates and another \doxylink{classCoordinates}{Coordinates} to define the maximum coordinates. Then it reads two \doxylink{classDateTime}{Date\+Time} objects, one \doxylink{classDateTime}{Date\+Time} to define the minimun \doxylink{classDateTime}{Date\+Time} and another \doxylink{classDateTime}{Date\+Time} to define the maximum \doxylink{classDateTime}{Date\+Time}. Next it reads an integer number n to define the number of \doxylink{classCrime}{Crime} objects to read. Thereafter, it reads n \doxylink{classCrime}{Crime} objects, saving in an array of Crimes only the Crimes whose \doxylink{classDateTime}{Date\+Time} is between the minimum and maximun Date\+Times and whose coordinates are valid (\begin{DoxySeeAlso}{See also}
\doxylink{classCoordinates_a71fcac9829eec3d1feecc63293a04973}{Coordinates\+::is\+Valid()} method description). Each \doxylink{classCrime}{Crime} object is normalized when inserted into the array. Be careful that the number of crimes inserted in the array does not exceed its capacity. Finally, the program shows in the standard output all the Crimes in the array and then all the Crimes which \doxylink{classCoordinates}{Coordinates} are inside the area defined by the minimum and maximum \doxylink{classCoordinates}{Coordinates} provided to the program. Be careful to show the output as in the below example.
