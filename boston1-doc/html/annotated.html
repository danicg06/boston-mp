 CCoordinatesGPS Coordinates (geographic coordinates) for measuring positions in the Earth. It consists of a pair of float values (latitude and longitude) that express angles (degrees). See for example Wikipedia Geographic coordinate system
Values for latitude are between -90 and 90, while values for longitude must be between -180 and 180. It is possible to build a Coordinates object with a latitude or longitude out of that ranges, but that object will be considered as invalid (method isValid() will return true).
The value latitude == 0 is the EQUATOR, and the value longitude == 0 is the Greenwich meridian.
