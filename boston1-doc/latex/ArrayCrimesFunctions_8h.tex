It takes the array of Crimes {\ttfamily crimes} as input and calculates the cumulative frequency distribution of crimes (histogram) by days of the week or by hours of the day. The histogram is saved in the array {\ttfamily histogram}. The \doxylink{classDateTime}{Date\+Time} field of each \doxylink{classCrime}{Crime} contains the information about when it took place. \begin{DoxyPrecond}{Precondition}
the array {\ttfamily histogram} should have enough capacity to save the calculated frequencies. Otherwise, possible runtime errors will be obtained 
\end{DoxyPrecond}

An example of output when using data\+Field==0 is the following\+: SUNDAY 25 MONDAY 11 TUESDAY 12 WEDNESDAY 5 THURSDAY 13 FRIDAY 17 SATURDAY 32
\item value 1 when the histogram contains frequencies by hours of the day. In this case, 24 lines will be displayed, one for each hour of the day; first line for hour 0, 1 for hour 1, and so on. An example of output when using data\+Field==1 is the following\+: 0 23 1 21 2 15 3 12 4 7 5 3 6 2 7 0 8 5 ...
\item Other values for data\+Field produce empty output Input parameter
