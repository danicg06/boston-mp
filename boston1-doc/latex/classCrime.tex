\doxysubsection{Detailed Description}
It stores data about a crime occurred in Boston city between 2017-\/01-\/20 02\+:00\+:00 and 2022-\/02-\/02 00\+:00\+:00 The data of each crime comes from a csv file located in \href{https://www.kaggle.com/datasets/shivamnegi1993/boston-crime-dataset-2022/data}{\texttt{ https\+://www.\+kaggle.\+com/datasets/shivamnegi1993/boston-\/crime-\/dataset-\/2022/data}} where some fields will be ignored. 

The selected fields for a \doxylink{classCrime}{Crime} are\+:
\begin{DoxyItemize}
\item 0 COUNTER\+: integer number that represents a counter that begins from 0 for each year.
\item 1 IDENTIFIER\+\_\+\+NUMBER\+: Identifier of the crime. It is an integer value stored as a string, that is, like "{}0020"{}. It is unique in a dataset of crimes. The string for this field must contain at least one character different from whitespace and \textbackslash{}t character. An ID will never contain leading or trailing blanks.
\item 2 OFFENSE\+\_\+\+CODE\+: string with an internal code whose group and description come in the next two fields.
\item 3 OFFENSE\+\_\+\+CODE\+\_\+\+GROUP\+: string with the group of the crime.
\item 4 OFFENSE\+\_\+\+DESCRIPTION\+: string with the description of the crime.
\item 5 DISTRICT\+: string with the district where the crime took place.
\item 6 REPORTING\+\_\+\+AREA\+: string with the area where the crime took place
\item 7 SHOOTING\+: a boolean where true represents that the crime was caused by a gunshot.
\item 8 OCCURRED\+\_\+\+ON\+\_\+\+DATE\+: date and time when the crime took place.
\item 9 STREET\+: name of the street where it took place.
\item 10 LOCATION (latitude, longitude) where it took place.
\end{DoxyItemize}
