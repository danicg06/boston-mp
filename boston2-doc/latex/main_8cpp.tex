\doxysubsubsection{\texorpdfstring{main()}{main()}}
{\footnotesize\ttfamily int main (\begin{DoxyParamCaption}\item[{int}]{argc,  }\item[{char \texorpdfstring{$\ast$}{*}}]{argv\mbox{[}$\,$\mbox{]} }\end{DoxyParamCaption})}

The purpose of this program is to read a list of crm files, each one containing information about a \doxylink{classCrimeSet}{Crime\+Set}, and make the fusion of all the Crime\+Sets, saving the result in a new file. The names of the input crm files are contained in a text file whose name is provided to the program as the first argument. The name of the output crm file can be provided to the program as the second argument (if not provided the output file is tests/output/output.\+crm). See below the Running sintax.

The program begins by checking if the number of arguments is valid. Next, it reads and saves in a dynamic array of \doxylink{classCrimeSet}{Crime\+Set} objects, each one of the crm files whose names are provided with the first argument of the program. Then, for each one of the \doxylink{classCrimeSet}{Crime\+Set} in the dynamic array, the following steps are done\+:
\begin{DoxyItemize}
\item Normalize the \doxylink{classCrimeSet}{Crime\+Set}. To do that, you can use the \doxylink{classCrimeSet_a03d46cbe5869b0fd4a3a4f877ae3832e}{Crime\+Set\+::normalize()} method.
\item Select only those Crimes with a valid location (discarding all with invalid location). To do that, you can use the \doxylink{classCrimeSet_a419c240e6a6b54257e175d3424c13110}{Crime\+Set\+::select\+Valid\+Location()} method.
\item Select only those Crimes where Shooting=="{}1"{}. To do that, you can use the \doxylink{classCrimeSet_af5c7b2e19957ed4fffa5e669d93431e7}{Crime\+Set\+::select\+Where\+EQ()} method. Hereafter, you must obtain a \doxylink{classCrimeSet}{Crime\+Set} with the fusion (join) of all the \doxylink{classCrimeSet}{Crime\+Set} in the array. See in the running examples, which comment should have the resulting \doxylink{classCrimeSet}{Crime\+Set}. Finally, the resulting \doxylink{classCrimeSet}{Crime\+Set} should be sorted and saved in an output file.
\end{DoxyItemize}
