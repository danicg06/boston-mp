int GetIndexPalette ( const ColorPalette &  palette,
float  frequency,
float  maxFrequency 
)

Computes the index into the given palette that corresponds to the provided frequency. This index is calculated as follow:

  • If frequency == maxFrequency then index=palette.getNumColors()-1;
  • Else index=frequency * palette.getNumColors() / maxFrequency
    Parameters
    paletteThe given palette. Input parameter
    frequencyThe input value for which we want to obtain its corresponding index in the palette. Input parameter
    maxFrequencyMaximum value of frequency to consider. It should be previously obtained as the maximum value in the frequency matrix. Input parameter
    Returns
    index into the Color palette that corresponds to the provided frequency
