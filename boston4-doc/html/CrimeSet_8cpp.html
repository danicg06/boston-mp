Overloading of the stream extraction operator for CrimeSet class.

Note
This operator should remove any crime previously contained in the provided CrimeSet crimeSet.
This operator throws an exception in some error cases (see below). Before throwing the corresponding exception, this operator clears the provided object (it calls to clear() method) to leave it in a consistent state.
This operator does not read the lines of comments, only the information about crimes (an integer n with the number of crimes and n lines with Crime information).
Exceptions
std::out_of_rangeThrows a std::out_of_range if the number of Crimes read from the file is negative.

crimeSetThe CrimeSet object to be filled. Input/output parameter
