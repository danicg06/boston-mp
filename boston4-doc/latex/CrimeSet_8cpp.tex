Overloading of the stream extraction operator for \doxylink{classCrimeSet}{Crime\+Set} class. 

\begin{DoxyNote}{Note}
This operator should remove any crime previously contained in the provided \doxylink{classCrimeSet}{Crime\+Set} {\ttfamily crime\+Set}. 

This operator throws an exception in some error cases (see below). Before throwing the corresponding exception, this operator clears the provided object (it calls to clear() method) to leave it in a consistent state. 

This operator does not read the lines of comments, only the information about crimes (an integer n with the number of crimes and n lines with \doxylink{classCrime}{Crime} information). 
\end{DoxyNote}
