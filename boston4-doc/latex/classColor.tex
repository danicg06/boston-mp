\doxysubsection{Detailed Description}
A color object \doxylink{classColor}{Color(red, green, blue)} is used to encapsulate colors in the default RGB color space. An RGB color value is specified with 3 components (alpha components)\+: red, green and blue. Each component is represented using and unsigned char value (alpha value) in the range 0 -\/ 255. Value of 255 means that the basic color is completely opaque and an alpha value of 0 means that the color is completely transparent. For example\+: 


\begin{DoxyItemize}
\item \doxylink{classColor}{Color(255, 0, 0)} represents red color, that is, red is set to its highest value (255), and the other two (green and blue) are set to 0
\item \doxylink{classColor}{Color(0, 255, 0)} represents green color
\item \doxylink{classColor}{Color(0, 0, 255)} represents blue color
\item \doxylink{classColor}{Color(0, 0, 0)} represents black color
\item \doxylink{classColor}{Color(255, 255, 255)} represents white color 
\end{DoxyItemize}
