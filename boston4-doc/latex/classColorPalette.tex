Builds a \doxylink{classColorPalette}{Color\+Palette} with a list of 4 intervals of "{}primary"{} colors and the red color (\doxylink{classColor}{Color(255, 0, 0)}). This constructor has 4 integer parameters to control the number of colors in each interval\+: 


\begin{DoxyEnumerate}
\item {\ttfamily da\+:} number of colors from dark blue \doxylink{classColor}{Color(0, 0, 255)} (included) to light blue \doxylink{classColor}{Color(0, 255, 255)} (not included).
\item {\ttfamily bl\+:} number of colors from light blue \doxylink{classColor}{Color(0, 255, 255)} (included) to green \doxylink{classColor}{Color(0, 255, 0)} (not included).
\item {\ttfamily gr\+:} number of colors from green \doxylink{classColor}{Color(0, 255, 0)} (included) to yellow \doxylink{classColor}{Color(255, 255, 0)} (not included).
\item {\ttfamily bl\+:} number of colors from yellow \doxylink{classColor}{Color(255, 255, 0)} (included) to red \doxylink{classColor}{Color(255, 0, 0)} (not included).
\end{DoxyEnumerate}

The total number of colors in the palette is the addition of all the tones in each interval plus 1 (red color).

Examples\+:
\begin{DoxyItemize}
\item \doxylink{classColorPalette}{Color\+Palette(0,0,0,0)} has only one color, the red one \doxylink{classColor}{Color(255, 0, 0)}
\item \doxylink{classColorPalette}{Color\+Palette(1,1,1,1)} has got 5 colors\+: \doxylink{classColor}{Color(0, 0, 255)}, \doxylink{classColor}{Color(0, 255, 255)}, \doxylink{classColor}{Color(0, 255, 0)}, ~\newline
 \doxylink{classColor}{Color(255, 255, 0)} and \doxylink{classColor}{Color(255, 0, 0)}.
\item \doxylink{classColorPalette}{Color\+Palette(3,0,0,0)} has 4 colors\+: \doxylink{classColor}{Color(0, 0, 255)}, \doxylink{classColor}{Color(0, 85, 255)}, \doxylink{classColor}{Color(0, 170, 255)} and \doxylink{classColor}{Color(255, 0, 0)}.
\end{DoxyItemize}

\begin{DoxyNote}{Note}
If the total number of colors in the new palette is greater than Color\+Palette\+::\+MAX\+\_\+\+NUMBER\+\_\+\+COLORS or any of the provided parameters is negative this constructor builds a palette using the values da=2, bl=2, gr=2, ye=2
\end{DoxyNote}
