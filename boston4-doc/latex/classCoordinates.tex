\doxysubsection{Detailed Description}
GPS \doxylink{classCoordinates}{Coordinates} (geographic coordinates) for measuring positions in the Earth. It consists of a pair of float values (latitude and longitude) that express angles (degrees). See for example \href{https://en.wikipedia.org/wiki/Geographic_coordinate_system}{\texttt{ Wikipedia Geographic coordinate system}} ~\newline
 Values for latitude are between -\/90 and 90, while values for longitude must be between -\/180 and 180. It is possible to build a \doxylink{classCoordinates}{Coordinates} object with a latitude or longitude out of that ranges, but that object will be considered as invalid (method \doxylink{classCoordinates_a71fcac9829eec3d1feecc63293a04973}{is\+Valid()} will return true).~\newline
 The value latitude == 0 is the EQUATOR, and the value longitude == 0 is the Greenwich meridian. ~\newline
 


\begin{DoxyItemize}
\item A point with a positive value for latitude is located in the northern hemisphere; a point with latitude==90 is in the North pole. ~\newline

\item A point with a negative latitudeis located in the southern hemisphere. ~\newline

\item A point with a positive longitude is located to the right of the Greenwich meridian. ~\newline

\item A point with a negative longitude is located to the left of the Greenwich meridian. ~\newline

\end{DoxyItemize}
