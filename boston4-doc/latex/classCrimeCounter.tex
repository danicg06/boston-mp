\doxysubsection{Detailed Description}
It is a helper class used to calculate the number of crimes (frequency) occurring within each one of the smaller areas (cells) in which is divided a given target geographical area of the world. The target geographical area is determined by the next two fields in this class (\doxylink{classCoordinates}{Coordinates} objects)\+: 


\begin{DoxyItemize}
\item \+\_\+bottom\+Left\+Coord\+: Bottom left corner of the target geographical area
\item \+\_\+top\+Right\+Coord\+: Top right corner of the target geographical area
\end{DoxyItemize}

The target geographical area is divided into smaller rectangular areas (cells) using a grid of n\+Rows x n\+Columns cells. ~\newline
 This class uses a dynamic two-\/dimensional matrix of integers to store the frequencies for each cell of the grid. Each integer in this matrix allows to save the frequency of one of the cells. The field \+\_\+frequency of this class is a pointer to that matrix.

Constructor of the class. It allocates memory for the two-\/dimensional matrix of frequencies and sets the \doxylink{classCoordinates}{Coordinates} (bottom left corner and top right corner) that defines the target geographical area. Each element of the matrix will be initialized with 0 in this constructor. If the provided number of rows or columns is less or equals to zero, the matrix will be set with 0 rows and columns. 

This constructor uses default values for the parameters {\ttfamily bottom\+Left\+Coord} and {\ttfamily top\+Right\+Coord} that have been taken from the border coordinates of the dataset for Boston city (1). That full dataset is the source of the different datasets used in this course. (1) (csv file located in \href{https://www.kaggle.com/datasets/shivamnegi1993/boston-crime-dataset-2022/data}{\texttt{ https\+://www.\+kaggle.\+com/datasets/shivamnegi1993/boston-\/crime-\/dataset-\/2022/data}}).

This constructor does not check this precondition.

{\footnotesize\ttfamily void Crime\+Counter\+::save\+As\+PPMText\+Image (\begin{DoxyParamCaption}\item[{const std\+::string \&}]{file\+Name,  }\item[{const \mbox{\hyperlink{classColorPalette}{Color\+Palette}} \&}]{palette,  }\item[{const std\+::string \&}]{comment = {\ttfamily "{}"{}} }\end{DoxyParamCaption}) const}



Saves the matrix of frequencies of this object as a PPM color image. In a PPM (portable pixmap format) color image, each pixel (\doxylink{classColor}{Color}) of the image is saved as three integer numbers\+: the red, green and blue components (each one in the range 0-\/255). This method follows the following steps to build the PPM file\+: 


\begin{DoxyItemize}
\item It saves the string "{}\+P3"{} in a line.
\item Then it saves the provided comments (if they are not empty). It is neccesary to insert the character \textquotesingle{}\#\textquotesingle{} at the beginning of the line.
\item Next it saves the number of columns and rows (separated by white space).
\item Next it saves the integer 255
\item Finally it saves the pixels of the image (three integers for each pixel) separated by white space. Pixels should be traversed by rows, and then by column.
\end{DoxyItemize}

In this method, each frequency value in the matrix, is translated to a color of the output image with the help of the functions int \doxylink{CrimeCounter_8cpp_a1e25c23589359588c3102e9fdea370a7}{Get\+Index\+Palette()} and \doxylink{classColorPalette_a359d577ca613a09d7d9c901a1c43a31c}{Color\+Palette\+::get\+Color()} in the following way\+:

int pixel\+Index = Get\+Index\+Palette(palette, log((\texorpdfstring{$\ast$}{*}this)(row,column)+1), log(max\+Frequency+1)); \doxylink{classColor}{Color} color = palette.\+get\+Color(pixel\+Index);

where max\+Frequency is the maximum frequency value found in the frequency matrix.
